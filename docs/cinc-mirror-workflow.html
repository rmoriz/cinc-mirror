How cinc-mirror ships a verified package

GitHub Actions runs the mirror every six hours. Every artifact passes one gate — the published SHA-256 — before any byte reaches GHCR or rsync; the ledger decides what is left to do, and verify, repair and incident acks re-enter at classify.
